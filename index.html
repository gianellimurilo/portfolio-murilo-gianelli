Quem eu sou

Desenvolvedor Back-end focado em Java e Python. Minha atuação vai além da escrita de código, envolve análise de requisitos, tomada de decisões técnicas e construção de sistemas que sustentam operações reais. Priorizo boas práticas, testes, documentação e arquitetura limpa. Acredito que software bem feito é aquele que funciona de forma silenciosa, estável e escalável.

O que eu faço

Minha atuação concentra-se no desenvolvimento da camada lógica das aplicações. Isso inclui criação de APIs RESTful, modelagem e otimização de bancos de dados relacionais e não-relacionais, desenvolvimento de microsserviços e automação de processos internos. Utilizo Java e Python como tecnologias principais, sempre aplicando padrões de projeto, testes automatizados e documentação técnica para garantir manutenibilidade e confiabilidade.

Meu objetivo

Meu objetivo é ir além do código: quero entender o problema antes de escrever a solução. Busco evoluir constantemente em arquitetura de software, boas práticas e novas tecnologias — sempre com o propósito de criar sistemas que façam diferença de verdade. A meta é clara: construir produtos sólidos, escaláveis e que as pessoas confiem em usar todos os dias.
